How a séance works

Three steps, one very old friend.

You never have to write the dead language yourself. You just have to be curious about it.

I.

Say what you need

Type a modern task in plain English, and attach a small file if it needs one.

II.

The ghost writes and runs it

Real COBOL, Fortran or BASIC appears line by line and runs in your browser. You’ll see the actual output.

III.

Bring it back to Python

Every line is explained, then translated to modern Python, and both results are checked against each other.

The spirits

Choose who answers.

Each language has its own temperament. Start with COBOL; that’s where the work is.

COBOL

b. 1959
The ledger keeper
ADD WS-AMOUNT TO WS-TOTAL
DISPLAY "TOTAL: " WS-TOTAL-OUT

Reads almost like English. Still behind a lot of payroll, banking and public records.

Fortran

b. 1957
The calculator
total = total + amount
print '(A,F10.2)', 'TOTAL:', total

Built for numbers. Still turns up in science and engineering code.

BASIC

b. 1964
The first teacher
40 LET T = T + A
50 GOTO 20

The language a generation learned on. Line numbers, GOTO and all.
Some of the systems that pay pensions and move money were written before most of us were born. The people who wrote them are retiring.

  • Get a plain-English reason for every line
