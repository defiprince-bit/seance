How a séance works

Three steps, one old friend

You never have to write the dead language yourself. You just have to be curious about it.

1

Say what you need

Type a modern task in plain English, and attach a small file if it needs one.

2

The ghost writes and runs it

Real COBOL, Fortran or BASIC appears line by line and runs on a real compiler. You see the actual output.

3

Bring it back to Python

Every line is explained, then translated to modern Python, and both results are checked against each other.

The spirits

Choose who answers

Each language has its own temperament. Start with COBOL, because that’s where the work is.

COBOL

b. 1959
The ledger keeper
ADD WS-AMOUNT TO WS-TOTAL
DISPLAY "TOTAL: " WS-TOTAL-OUT

Reads almost like English. Still behind a lot of payroll, banking and public records.

Fortran

b. 1957
The calculator
total = total + amount
print '(A,F10.2)', 'TOTAL:', total

Built for numbers. Still turns up in science and engineering code.

BASIC

b. 1964
The first teacher
40 LET T = T + A
50 GOTO 20

The language a generation learned on. Line numbers, GOTO and all.
Some systems that pay pensions and move money are older than we are. The people who wrote them are retiring.

Séance is a gentle first hour with COBOL and its cousins. You don’t install a compiler or read a 600-page manual first.

Ask about something you already know how to do, and watch how it was done before you were born.

The candles are lit. Ask anything.

Your first séance takes about a minute.
